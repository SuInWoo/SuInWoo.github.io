# [CS] 자바의 JVM 구조와 가비지 컬렉션(GC)

자바 프로그램을 실행하기 위한 가상 머신입니다. OS에 종속되지 않고 실행할 수 있게 해줍니다.

---

## 정리

## JVM(Java Virtual Machine)이란?

자바 프로그램을 실행하기 위한 가상 머신입니다. OS에 종속되지 않고 실행할 수 있게 해줍니다.

### 주요 구성 요소

- Class Loader: .class 파일을 읽어 Runtime Data Area에 배치합니다.

- Execution Engine: 바이트코드를 실행합니다.

- Runtime Data Area: JVM이 프로그램을 수행하기 위해 할당받은 메모리 공간입니다.

### 가비지 컬렉션(GC)

힙(Heap) 영역에서 참조되지 않는 객체들을 자동으로 삭제하여 메모리를 관리합니다.
