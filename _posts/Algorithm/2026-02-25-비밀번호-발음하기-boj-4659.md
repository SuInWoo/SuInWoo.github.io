# 비밀번호 발음하기 (BOJ 4659)

## 📖 문제 설명

주어진 문자열이 특정 조건을 만족하면 acceptable,

그렇지 않으면 not acceptable을 출력하는 문제이다.

입력은 여러 줄로 주어지며 "end"가 입력되면 종료한다.

## ✅ 조건 정리

- 조건 1: 모음(a, e, i, o, u)이 최소 1개 이상 포함되어야 한다.

- 조건 2: 모음이 3개 연속 또는 자음이 3개 연속이면 안 된다.

- 조건 3: 같은 글자가 2번 연속으로 오면 안 된다.

- 입력 범위: 문자열 길이는 최대 20

- 출력 형식:

## 💡 풀이 방법



## 1️⃣ 접근 아이디어

한 글자씩 순회하면서 다음을 동시에 체크한다:

- 모음 존재 여부

- 모음/자음 연속 개수

- 동일 문자 연속 여부

이를 위해 다음 변수를 사용했다:

- prev : 이전 문자

- prevIsVowel : 이전 문자가 모음인지 여부

- cnt : 모음 또는 자음이 연속된 개수

- hasVowel : 모음 포함 여부

- isPass : 조건 통과 여부

## 2️⃣ 핵심 로직 설명



## ✔ 모음 포함 여부 체크

문자열을 순회하면서 모음이 나오면 hasVowel = true

## ✔ 모음/자음 3연속 체크

- 현재 문자와 이전 문자의 모음 여부 비교

- 같으면 cnt++

- 다르면 cnt = 1

- cnt == 3이면 탈락

## ✔ 동일 문자 연속 체크

```
이전 문자 == 현재 문자
AND
현재 문자가 e, o 가 아니면 탈락
```

## ✔ 마지막에 모음 존재 여부 확인

hasVowel == false이면 탈락 처리

## 💻 코드

```
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Boj4659 {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        while (true) {
            String target = br.readLine();
            if (target.equals("end")) break;

            boolean hasVowel = false;
            boolean isPass = true;

            char prev = target.charAt(0);
            boolean prevIsVowel = checkChar(prev);
            int cnt = 1;

            if (prevIsVowel) hasVowel = true;

            for (int i = 1; i < target.length(); i++) {
                char curr = target.charAt(i);
                boolean currIsVowel = checkChar(curr);

                // 모음 존재 체크
                if (currIsVowel) hasVowel = true;

                // 동일 문자 연속 체크 (ee, oo 제외)
                if (prev == curr && curr != 'e' && curr != 'o') {
                    isPass = false;
                    break;
                }

                // 모음/자음 연속 체크
                if (prevIsVowel == currIsVowel) {
                    cnt++;
                    if (cnt == 3) {
                        isPass = false;
                        break;
                    }
                } else {
                    cnt = 1;
                }

                prev = curr;
                prevIsVowel = currIsVowel;
            }

            if (!hasVowel) isPass = false;

            if (isPass)
                sb.append("<").append(target).append("> is acceptable.\n");
            else
                sb.append("<").append(target).append("> is not acceptable.\n");
        }

        System.out.print(sb);
    }

    public static boolean checkChar(char c) {
        return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
    }
}
```

## ⏱ 시간 복잡도

- 시간복잡도: O(N)

- 공간복잡도: O(1)

## 🔎 배운 점 / 느낀 점

- 여러 조건을 한 번에 처리하려고 하면 로직이 꼬이기 쉽다.

- 연속 조건은 “모음/자음”과 “동일 문자”를 분리해서 생각해야 깔끔해진다.

- 문제 조건을 각각 독립적으로 관리하는 것이 중요하다.
